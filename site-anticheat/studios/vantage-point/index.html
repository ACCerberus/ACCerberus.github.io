The studio

Vantage Point Games makes tactical shooters for people who read the manual

We started in 2016 with six people and a milsim mod that had gotten out of hand. We still work the same way: model the weapon properly, model the map properly, and let the fight follow from that. We do not ship features we cannot explain in a patch note.

What we make

Three things we take seriously

Weapon systems

Ballistics, recoil, and handling built from published data and then tuned by hand. Every value is visible in-game.

Readable maps

Terrain designed around sightlines and cover, not set dressing. Grid references work. So does the range card.

Competitive integrity

A ranked ladder is only worth playing if the results are real. We invest in matchmaking, telemetry, and anti-cheat accordingly.
