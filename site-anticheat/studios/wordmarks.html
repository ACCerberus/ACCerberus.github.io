Studio wordmarks — plain reference snippet

Monochrome inline SVG, all strokes and fills use currentColor, so each mark takes the colour of whatever it is dropped into. Same five marks are used on /studios/<slug>/, on the case-study cards, and are safe to reuse in the homepage trusted-by strip. Size them with CSS height (width: auto); intrinsic viewBox is 0 0 240 36. This page is a reference sheet only — it is not linked from anywhere and is marked noindex.
