Recent Incidents
RESOLVED False positive spike on UE5.4 overlay rendering May 14, 2026
Behavioral AI flagged legitimate Unreal Engine 5.4 Slate overlay rendering as an external screen reader on 3 partner titles. Affected ~240 sessions over 22 minutes.
Root cause: UE5.4 changed GDI hook pattern for overlay compositing. Signature whitelist updated within 22 minutes. No bans issued — all flagged sessions were held in manual review queue.
Resolution time: 22 minutes. Postmortem completed. Added UE5.4 overlay pattern to trusted whitelist.
RESOLVED Elevated scan latency on AMD Ryzen 9000 series Apr 30, 2026
PCIe bus enumeration taking 8-12ms on Zen 5 CPUs due to new IOMMU topology. Scan cycle exceeded 3ms budget on first pass.
Root cause: Zen 5 IOMMU groups differ from Zen 4. Added topology-aware enumeration path. Resolution time: Fixed in v0.4.1-beta, deployed Apr 28.
RESOLVED Webhook delivery delays Apr 18, 2026
Ban event webhooks delayed by 45-90 seconds due to queue backlog during concurrent pentest run across all 4 titles.
Root cause: Queue worker pool undersized for burst load. Scaled from 2 to 6 workers. Resolution time: 35 minutes.
RESOLVED Dashboard API 503 errors Mar 29, 2026
Threat dashboard returned 503 for ~8 minutes during signature database reindex. Detection engine was unaffected — clients continued scanning normally.
Root cause: DB reindex locked read replica. Moved reindex to off-peak window. Resolution time: 8 minutes.
